# Vortex Control Motor Driver

The motion board for **Vortex Control**, a vertical pinball machine that is still in progress. It drives two stepper motors, reads two joysticks and four limit switches, and follows signals from the main (score display) board to run each game.

Board: Dual Motor / Dual Joystick / Quad Limit Switch Driver Card REV 0.2, designed by [Just Different Creations](https://justdif.com) in Lufkin, Texas. See it on the [PCB-Only Builds](https://justdif.com/pcb-only-builds/) page. The main board's code is in [Vortex-Score-Display](https://github.com/JustDifferentCreations/Vortex-Score-Display).

## How it works

On power-up the board calibrates: both motors run up to their top limit switches, then down to their bottom switches, and the board waits there with the drivers switched off.

| State | What happens |
| --- | --- |
| Calibrate | Drive both motors to the top limits, then to the bottom limits |
| Idle (game over) | Motors parked at the bottom, drivers disabled, "waiting for start" output high |
| Go to start | Drivers enabled, motors climb to their start positions (`START_STEPS_M1` = 500, `START_STEPS_M2` = 750 steps, or the top limit) |
| Player control | Joystick 1 moves the left motor and joystick 2 the right motor, up or down, stopping at the limit switches |
| Next round | Control is taken away, both motors home to the bottom, then return to their start positions |
| Game over | Control is taken away, both motors home to the bottom, then the board goes idle |

The motors step at about 5 kHz (100 µs high, 100 µs low) on every loop.

## Signals with the main board

| Pin | Name | Direction | Meaning |
| --- | --- | --- | --- |
| PF0 | MC1 | In (falling edge) | Next round: home the motors and return them to start |
| PF1 | MC2 | In (falling edge) | Game over: home the motors and power down |
| PA4 | MC3 | In (falling edge) | New game (only while idle): enable drivers and go to start |
| PA6 | MC5 | Out | High while the player has control |
| PA7 | MC6 | Out | High while parked and waiting for a new game |
| PA5 | MC4 | | Reserved, not used yet |

## Other pins (AVR64DU28)

| Pin | Name | Function |
| --- | --- | --- |
| PD0 / PD1 | JOY_1_UP / JOY_1_DN | Joystick 1 up / down (active low, pull-up) |
| PD2 / PD3 | JOY_2_UP / JOY_2_DN | Joystick 2 up / down (active low, pull-up) |
| PD4 / PD5 | LIMIT_UP_L / LIMIT_UP_R | Top limit switches, left / right (active low, pull-up) |
| PD6 / PD7 | LIMIT_DN_L / LIMIT_DN_R | Bottom limit switches, left / right (active low, pull-up) |
| PA2 / PA3 | DIR_M1 / STEP_M1 | Left motor direction / step |
| PA0 / PA1 | DIR_M2 / STEP_M2 | Right motor direction / step |
| PC3 | ENABLE_PC3 | Stepper driver enable (low = enabled) |

## Building and flashing

- MPLAB X IDE with the XC8 compiler (built with v3.10)
- Programmer: PICkit 5
- Pins, clock and the pin-change interrupts are set up with MPLAB Code Configurator (MCC Melody). The `mcc_generated_files` folder is not in this repo. Open the project in MPLAB X, open MCC (it loads `AVR64DU28_ICB_Motor.mc3`), click **Generate**, then build and program the board.

## Status

Vortex Control is still being built, so this code will keep changing.
